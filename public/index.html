    How this system works

    1. You type a wish. enters the context
    2. Server adds the printer's system instructions + knowledge (inks, catalog, taste rules). deterministic
    3. The model (via OpenRouter) completes the conversation: a reply and, when ready, a scene recipe as JSON. probabilistic
    4. Validator clamps the recipe to the press: ≤3 inks, catalog items only, counts. Fixes appear in the press log. deterministic
    5. 3D press builds the tank, renders how much of each ink every spot gets, screens each drum as halftone dots, and overprints them off-register on paper. deterministic

    The model never sees the picture it made, only its own recipe. You decide when the print is final.
